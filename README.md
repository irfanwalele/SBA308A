#Cat Breed Explorer

Cat Breed Explorer is a single-page JavaScript web application created for SBA 308A.

#Description
This application allows users to select a cat breed and view cat images from The Cat API. Users can also add individual cat images to their favorites.

## Features

- Loads cat breeds from an external API
- Searches for cat images by breed
- Uses GET requests to retrieve data
- Uses a POST request to add images to favorites
- Displays loading, success, and error messages
- Uses JavaScript modules
- Uses Promises and async/await
- Uses DOM manipulation and event listeners

## Technologies Used

- HTML
- CSS
- JavaScript
- The Cat API
- Fetch API

## JavaScript Files

- `api.js` handles API requests
- `ui.js` handles DOM updates
- `main.js` handles events and application logic

## How to Run

Select a breed and click Search.
Click Add to Favorites to save a cat image.
